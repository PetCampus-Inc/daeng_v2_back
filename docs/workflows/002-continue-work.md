# 진행 중인 작업 이어하기

이 workflow는 기존 작업의 맥락을 복구하는 진입 절차다. Jira나 브랜치를 변경하지 않으며, 기존 작업 문서와 현재 작업 트리를 읽기 전용으로 확인한 뒤 사용자의 확인을 받는다.

## 1. 기존 작업 식별

- Jira 키, 작업 브랜치, 기존 `docs/work/` 문서 또는 PR을 확인한다.
- 현재 브랜치와 사람이 제공한 작업 브랜치가 다르면 알리고 중단한다. AI는 브랜치를 변경하지 않는다.

## 2. 맥락 복구

- 기존 작업 문서의 목표·범위·제외 범위·결정·완료 기준을 읽는다.
- 현재 diff, 최근 커밋, 이전 검증 결과를 대조해 완료한 것과 미완료인 것을 구분한다.
- 문서와 코드가 어긋나면 수정 전에 사람과 범위를 다시 확인한다.

## 3. 작업 재개

- 기존 작업의 유형에 맞는 `000-common.md` 및 유형별 workflow를 다시 적용한다.
- 다음 구현 또는 검증 단계와 사용자 확인이 필요한 사항을 제시한 뒤 승인받아 진행한다.
