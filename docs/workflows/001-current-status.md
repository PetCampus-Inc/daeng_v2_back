# 현재 상태 점검 및 다음 작업 제안

이 workflow는 작업을 시작하기 전 저장소 상태를 읽기 전용으로 파악하는 진입 절차다. Jira 티켓을 생성·수정하거나 브랜치를 생성·checkout·변경하지 않으며, `000-common.md`를 적용하지 않는다.

## 1. 점검 범위 확인

- 현재 브랜치, 작업 트리 변경사항, 최근 커밋과 원격 추적 상태를 확인한다.
- 진행 중인 `docs/work/` 문서, 관련 PR·에픽·미결 작업을 확인할 수 있는 범위에서 읽는다.
- 테스트·빌드 상태는 최근 결과가 확인되는 경우에만 보고하며, 실행하지 않은 검증을 통과한 것으로 말하지 않는다.

## 2. 결과 제시

- 확인된 사실, 미확인 항목, 현재 작업 트리의 충돌 위험을 구분해 요약한다.
- 다음 작업 후보를 영향·의존성·위험 기준으로 제안하되, 우선순위를 임의로 확정하지 않는다.

## 3. 다음 단계 전환

- 사용자가 작업을 선택하면 해당 번호의 workflow를 읽는다.
- Jira 티켓 기반 변경 작업으로 전환되면 사용자에게 Jira 키와 사람이 생성한 작업 브랜치를 받고 `000-common.md`와 유형별 workflow를 적용한다.
