# 0005. 리뷰 크롤링(블로그 리뷰, Selenium 기반) 마이그레이션 보류

## 맥락

`GET /kindergarten/{placeId}/blog-reviews`는 Selenium + WebDriverManager 기반의 블로그 리뷰 크롤링 기능이다. 이번 스프린트에 함께 마이그레이션할지 결정이 필요했다.

## 검토한 후보

1. 이번 스프린트에서 Selenium 의존성을 그대로 신규 서버에 포팅한다.
2. 크롤링만 별도 서비스로 분리한다.
3. 이번 스프린트에서는 결론 내지 않고 보류한다 — 컷오버 이후에도 레거시 서버로 리버스 프록시.

## 결정

**후보 3 — 이번 스프린트 보류.**

근거: Selenium + WebDriverManager라는 무거운 의존성을 그대로 옮길지, 별도 서비스로 분리할지 결론이 나지 않았다. 컷오버 일정을 이 결정 하나 때문에 늦추지 않기 위해 우선 리버스 프록시로 우회한다.

## 결과

- `GET /api/v0/kindergarten/{placeId}/blog-reviews`는 컷오버 이후에도 리버스 프록시로 레거시 자바 서버에 임시로 남겨둔다.
- 최종 아키텍처(그대로 이관 vs 별도 서비스 분리)는 후속 스프린트에서 재검토한다 — 아직 미결정.
