# ADR 인덱스

append-only 목록이다. 상태(활성/대체됨) 컬럼은 두지 않는다 — 새 ADR을 쓸 때마다 과거 이력 전체를 뒤져 충돌 여부를 표시해야 하는 부담이 생기기 때문이다. 같은 주제를 다루는 ADR이 여러 개면 번호가 큰 쪽이 더 나중 논의이지만, 항상 옳다는 뜻은 아니다 — 각 ADR의 맥락 절에서 이전 결정 언급을 확인한다.
